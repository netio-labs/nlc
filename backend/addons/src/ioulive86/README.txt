IOUlive86 is an open-source drop-in replacement for IOUlive, a proprietary
application written by cisco Systems, Inc.

IOUlive86 allows you to "bridge" virtual routers and switches running on
the Cisco IOS-on-UNIX (IOU) software to a physical network.

For more information on Cisco IOU and IOUlive86, see:
http://evilrouters.net/cisco-iou-faq/

IOUlive86 is developed by an author who wishes to remain anonymous.

The source code is maintained by Jeremy L. Gaddis <jlgaddis@gnu.org>
and hosted at https://github.com/jlgaddis/ioulive86/

--------------------------------------------------------------------
NLC build notes
--------------------------------------------------------------------

This tree is a modified ioulive86 used by NLC (Network Lab Conductor):

  * Single process driven by poll(); no fork, no busy-wait on connect.
    Frames towards IOU use sendto(), so a stopped IOU peer only shows
    up as a "dropped" counter.
  * Built-in TCP console:  -p <port> [-t <title>]
    Same telnet negotiation as wrapper-linux. Every Enter prints
    "ioulive86 is working with physical interface <intf>" plus frame
    counters. SIGHUP closes the console client, SIGTERM exits cleanly.
  * Privilege drop: the raw socket is opened first, then, when started
    through sudo, the process switches to SUDO_UID/SUDO_GID so that the
    netio socket directory (/tmp/netio<uid>) matches the IOU processes
    and the backend can signal it without root.
  * NETMAP: the ioulive86 instance may appear on either side of a line.
  * Offload repair (PACKET_AUXDATA): frames generated by the local host and
    tapped before hardware offload get their TCP/UDP checksum recomputed
    (TP_STATUS_CSUMNOTREADY), and 802.1Q tags stripped by rx VLAN offload are
    reinserted. Without this, host <-> IOU pings work but TCP hangs, and
    trunk VLANs lose their tags. No ethtool -K tweaks are needed.

Usage:
  ioulive86 -i <interface> [-n NETMAP] [-p <console port>] [-t <title>] <instance ID>

Build / install:
  make && make install     (copies the binary to backend/addons/iou/)
