# 控制台

NLC 为 Lab 中的每个节点提供基于浏览器的终端控制台，由 xterm.js 通过 WebSocket 实现。无需 SSH 客户端或外部终端模拟器。

## 打开控制台

点击拓扑查看器概览面板中的 **控制台**（Console）按钮。这会在新的浏览器标签页中打开控制台页面，范围限定为当前 Lab。

> 只有在 Lab 已加载时，控制台按钮才可用。

## 界面

控制台页面顶部有一个标签栏，Lab 中的每个节点对应一个标签。标签之间以竖线分隔。当前活动的标签以黄色高亮显示。

点击标签即可为该节点打开终端会话。终端只有在你第一次点击其标签时才会连接——未激活的标签不占用连接。

## 连接到节点

第一次点击某个标签时，NLC 会：

1. 向节点的控制台端口发送重置请求（等同于拓扑查看器中的 **重置控制台**（Reset Console）按钮）。
2. 建立到后端控制台代理的 WebSocket 连接。
3. 将一个 xterm.js 终端附加到该连接上。

终端会显示以下状态消息：

- `Resetting console…`——正在重置
- `Connected.`——WebSocket 已建立，终端可用
- `Disconnected.`——WebSocket 已关闭（节点已停止、Lab 已卸载或网络问题）
- `WebSocket error.`——连接失败

## 重置控制台会话

每个标签在节点名称右侧都有一个小的重置按钮（圆形箭头图标）。点击后会：

1. 在后端重置节点的控制台端口。
2. 断开现有的 WebSocket 连接。
3. 打开一个新的终端并重新连接。

当控制台会话无响应或卡住时（例如节点重载之后），这一功能很有用。

## 终端行为

- 终端会自动调整大小以适应浏览器窗口。
- 输入通过 WebSocket 逐字符发送。
- 输出实时流式传输。
- 支持标准 ANSI 转义序列和颜色代码。
- 默认字号 14px，可在右键菜单中放大、缩小或重置；深色背景（`#18181b`）。

## 使用外部终端连接

每个节点的控制台端口都以标准 telnet 端口的形式开放。要使用任意终端模拟器（例如 PuTTY、SecureCRT 或系统自带的 `telnet` 命令）连接：

1. 在拓扑查看器中点击该节点，在左侧面板中查看其详情。
2. 记下其中显示的 **控制台端口**（Console port）值。
3. 通过 telnet 连接：

```bash
telnet <BACKEND_IP> <console_port>
```

如果连接被拒绝或终端无响应，请点击左侧面板中的 **重置控制台** 重置端口，然后重试。
