# 设置

设置页面用于管理镜像、运行时、后端连接，以及连接到服务器的浏览器 Shell。可从顶部导航栏进入。

## 镜像

镜像区域列出后端当前可用的所有镜像文件。

### 镜像命名

NLC 根据文件名前缀识别节点 Profile：

| Profile | 文件名前缀       |
| ------- | ---------------- |
| Router  | `I86BI_LINUX`    |
| Switch  | `I86BI_LINUX_L2` |

不符合上述任一前缀的文件在上传时会被拒绝。

### 上传镜像

点击 **上传镜像**（Upload Image）并选择文件。文件会直接从浏览器上传到后端。上传期间请勿离开页面。

### 删除镜像

点击列表中任意镜像旁的 **删除**（Delete）。文件会立即从后端移除。

## 运行时

运行时区域用于设置存储在后端的 IOU/IOL 密钥。

### 更新 IOU/IOL 密钥

1. 进入 **设置 → 运行时**（Settings → Runtime）。
2. 在 **更新 IOU/IOL 密钥**（Update IOU/IOL key）字段中输入密钥。
3. 点击 **保存**（Save）。

更改对保存之后启动的所有节点立即生效。已在运行的节点在重新启动之前不会使用新密钥。

## 后端

后端区域用于配置前端如何访问后端服务器。

### Internal URL

Next.js 服务器以服务器到服务器的方式直接调用后端时使用的 URL。默认为 `http://localhost:8080`。当前端和后端运行在同一台机器上时，通常无需更改。

### Public URL

浏览器连接后端 WebSocket（控制台、抓包、Shell）时使用的 URL。

留空时，浏览器按当前页面地址自动推算后端地址：

| 浏览器访问地址               | 自动连接的后端地址                                     |
| ---------------------------- | ------------------------------------------------------ |
| `http://192.168.56.129`      | `ws://192.168.56.129/v1`（经 Nginx 转发）              |
| `https://lab.example.com`    | `wss://lab.example.com/v1`（经 Nginx 转发）            |
| `http://192.168.56.129:3000` | `ws://192.168.56.129:8080/v1`（端口取自 Internal URL） |
| `http://localhost:3000`      | Internal URL                                           |

以下情况需要手动填写：

- 反向代理使用非标准端口（例如 `http://192.168.56.129:8000`）
- 后端位于另一台主机，或对外地址与前端不同

## Shell

Shell 区域是一个基于浏览器的 SSH 终端，连接到**后端服务器本身**，便于执行主机层面的任务（管理 Podman 镜像和卷、检查进程）。

### 连接

1. 进入 **设置 → Shell**（Settings → Shell）。
2. 输入后端主机上某个 Linux 账户的 **用户名**（Username），然后点击 **连接**（Connect）。
3. SSH 服务器会在终端中提示输入密码，在终端中输入即可。
