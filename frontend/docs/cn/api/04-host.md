# 主机

## `GET /v1/host/interfaces`

列出服务器上的物理（以太网）网络接口。用于填充 IOULive86 Bridge 节点的 **接口（Interface）** 下拉框。

**响应 `200`**

```json
{
  "ok": true,
  "data": {
    "interfaces": [
      { "name": "eth0", "operstate": "UP", "address": "00:15:5d:54:8d:27", "mtu": 1500 }
    ]
  }
}
```

只返回链路类型为以太网的接口；`lo` 和非以太网链路会被忽略。`address` 为 MAC 地址（不可用时为 `null`），`mtu` 可能为 `null`。列表反映请求时刻服务器上的接口；即使之前保存的接口已不存在，前端仍会保留它作为可选项。

在极少数情况下服务器无法枚举接口（底层 `ip link show` 执行失败），此时接口返回 `500`。

## `WS /v1/host/shell`

在浏览器中通过 SSH 终端登录**后端主机本身**（参见[设置](../guide/06-settings.md#shell)指南）。这是一个 WebSocket，在浏览器与运行于 pty 上的系统 `ssh` 客户端之间转发原始终端字节；认证由主机的 `sshd` 通过 ssh 客户端自身的密码提示完成——NLC 不会接触到凭据。

**查询参数**

| 参数 | 说明 |
|---|---|
| `session` | 客户端生成的会话 ID（`[A-Za-z0-9-]{8,64}`）。使用相同 ID 重连会重新接入仍在运行的会话，并回放其最近的输出。 |
| `user` | 后端主机上的登录用户名（`[A-Za-z0-9][A-Za-z0-9._-]{0,31}`）。 |

目标主机在服务端固定为 `localhost`，客户端无法指定，因此后端永远不会被用作 SSH 跳板机。会话在断开后仍会保留，无客户端连接 30 分钟后被回收。对仍在运行的会话发起第二个客户端连接会被拒绝（关闭码 `1008`，“session busy”）；`user`/`session` 无效时同样以 `1008` 关闭。
